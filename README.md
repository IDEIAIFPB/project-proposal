# Proposal FrontEnd

Este projeto tem como objetivo avaliar a viabilidade do uso conjunto das tecnologias **Next.js**, **TypeScript** e **Tailwind CSS** no desenvolvimento de aplicações web modernas.

## Tecnologias Utilizadas

- **Next.js**: `15.3.2`  
  Framework React para aplicações com renderização híbrida (estática e SSR).

- **React**: `19.0.0`  
  Biblioteca para construção de interfaces de usuário.

- **TypeScript**: `^5`  
  Superset do JavaScript que adiciona tipagem estática ao código.

- **Tailwind CSS**: `^4`  
  Framework utilitário para estilização rápida e responsiva.

## Objetivo

Analisar os seguintes aspectos das tecnologias utilizadas:

- **Facilidade de configuração e uso**
- **Produtividade durante o desenvolvimento**
- **Organização e legibilidade do código**
- **Performance da aplicação**
- **Manutenibilidade e escalabilidade do projeto**

## Estrutura do Projeto

A estrutura básica segue os padrões recomendados pelas tecnologias:

```
/project-root
│
├── public/           # Arquivos estáticos
├── src/app/          
│   ├── pages/        # Páginas do Next.js
│   └── components/   # Componentes reutilizáveis
│
├── next.config.js
├── package.json
└── tsconfig.json
```

## Instalação e Execução

1. Clone o repositório:

   ```bash
   git clone https://github.com/IDEIAIFPB/project-proposal.git
   cd project-proposal
   ```

2. Instale as dependências:

   ```bash
   npm install
   ```

3. Inicie o servidor de desenvolvimento:

   ```bash
   npm run dev
   ```
